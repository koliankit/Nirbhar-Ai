## Overview

**Nirbhar AI** is an enterprise-grade AI platform designed to help Indian and global businesses operate smarter, faster, and more efficiently. From intelligent conversational AI to automated report generation and real-time business insights — Nirbhar AI is the intelligent backbone of your enterprise.

| Feature | Description |

## Design System

### Colors
| Token | Value | Usage |
|---|---|---|
| `--cyan` | `#00E5FF` | Primary accent, highlights |
| `--blue` | `#0066FF` | Secondary accent, gradients |
| `--bg-primary` | `#030810` | Main background (dark) |
| `--bg-card` | `#0A1628` | Card backgrounds |
| `--text-primary` | `#F0F6FF` | Headings, key text |
| `--text-secondary` | `#8AA3C0` | Body copy |

### Typography
- **Display / Headings**: Syne (800 weight) — bold, technical personality
- **Body / UI**: DM Sans — clean, readable, professional
- **Code / Tags**: JetBrains Mono — technical credibility

### Breakpoints
| Name | Width |
|---|---|
| Mobile | `< 480px` |
| Tablet | `480px – 768px` |
| Desktop | `768px – 1024px` |
| Wide | `> 1024px` |

## Getting Started

### Local Development

Simply open `index.html` in any modern browser — no build step required.

```bash
# Optional: serve with a local server
npx serve .
# or
python -m http.server 3000
```

Then open: `http://localhost:3000`
